# Tote

A local-first programmatic UIKit app for iOS 26 that unifies campus parcel pickup codes, tracking numbers, and locker access.

## Development

Open `Tote.xcworkspace`, or use:

```bash
mise install
mise run-ios
mise check    # run before each commit
```

See [AGENTS.md](AGENTS.md) for the project rules and [docs/DECISIONS.md](docs/DECISIONS.md) for architecture and delivery decisions.
